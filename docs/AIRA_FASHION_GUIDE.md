# AIRA Fashion Guide

AIRA の衣装を Z世代ファッション誌系の2026年トレンドに沿って管理するためのルール集です。
コードの正本は `src/fashion/styleRules.js`（ルール）と `src/fashion/outfits.js`（衣装設定）です。このドキュメントはその意図の説明です。

> 記事は「流行の方向性」の参考にしただけで、画像・本文・商品名・ブランドロゴは使っていません。
> 衣装はすべてローポリのオリジナル形状です。

## 固定条件（変更しない）

顔・目・眉・頬・頭の形・髪型・体型・ローポリ表現は衣装によって変えません。
衣装ごとに変えてよいのは `hat` の色柄、`top`、`bottom`、`shoes`、`accessories` だけです。

## スロット構成

| スロット | 内容 |
| --- | --- |
| `hat` | 帽子（`type: 'beanie'`、パレット、`ears` で耳の有無） |
| `top` | トップス／ジャケット（`type`、`color`、`accent`、`inner`） |
| `bottom` | ボトムス（`type`、`color`、`light`、`accent`） |
| `shoes` | 靴（`type: 'sneaker' \| 'boot'`） |
| `accessories` | 小物の配列（`{ type, color }`） |

## 4つのスタイル

### 1. K-STREET（`kstreet`）
- 構成：クロップドトップス + 極太バギーデニム + 厚底スニーカー + 耳付き帽子
- シルエット：短い上半身 × 太い下半身で「下に重心」。帽子の耳でも正面から見分けられる。
- 色：白 × デニムブルー、差し色はアイスブルー／イエロー／ピンク
- 小物：アイスブルーのバッグ + イエローのチャーム
- 参考：K-BRAND特集（アイスブルーのバッグを主役にするコーデ、ホワイトデニム × アイスブルーのトーン合わせ）、バッグにチャームを付ける定番化

### 2. NEO GYARU（`gyaru`）
- 構成：ミニスカート + ショート丈ジャケット + 厚底ブーツ + ピンクアクセサリー
- シルエット：超ミニで脚を見せ、黒いブーツで締める。
- 色：黒 × ホットピンク。ピンクは小物（ハートネックレス、ヘアクリップ、チョーカー、バッグチャーム）で効かせる
- 参考：4大K-COREの「Y2K日本ギャル」。詳細な着こなしは記事に無いため、指定された構成とピンク小物のルールで設計した。

### 3. SPORTY MIX（`sporty`）
- 構成：トラックジャケット + パラシュートパンツ + スポーツ小物（リストバンド、腰巻き）
- シルエット：光沢のあるシャカシャカ素材。膝が膨らみ裾が絞れる、ひし形のシルエット。
- 色：シルバーグレー × ブラック、差し色はネオンピンク
- 参考：4大K-COREの「ハイテクなスポーツMIX」、オフランウェイの「シャカシャカトップス」「ジャージ合わせ」、スナップの「腰回りに何かしら重ねる」

### 4. CITY MODE（`city`）
- 構成：オーバーサイズジャケット + ワイドデニム + 差し色バッグ
- シルエット：肩が落ちた大きなジャケットに、まっすぐ落ちるワイドデニム。耳なしの帽子で大人っぽく。
- 色：ブラウン × ダークデニム、差し色は1点だけ（ビビッドオレンジのバッグ）
- 参考：4大K-COREの「都会的なシティオンニ」、オフランウェイの「でかジャケット」「差し色のロングブーツ」「抜け感」

## 共通ルール

1. **5スロット必須**：`hat / top / bottom / shoes / accessories` がすべてあること。
2. **スタイルごとの許可タイプ**：`styleRules.js` の `allowed` に含まれる部位だけ使う。
3. **必須小物**：各スタイルの `requires.accessories` を満たす（例：NEO GYARU はハート・クリップ・チョーカー・チャーム）。
4. **差し色は絞る**：ベース色 + 差し色1〜2色。
5. **シルエットを被らせない**：トップス × ボトムスの組み合わせが他のスタイルと同じにならない（`findSilhouetteClashes`）。
6. **小さい画面でも分かる**：形の違い（短丈／ミニ／膨らみ／腰丈）で見分けられるようにし、色だけに頼らない。細かい装飾は付けすぎない。

これらは `npm test`（`tests/fashion.test.js`）で自動チェックされます。

## 新しいスタイルを足す手順

1. `styleRules.js` の `STYLE_RULES` にルール（名前、キーワード、許可タイプ、必須小物、返答文）を追加
2. `outfits.js` の `STYLE_OUTFITS` に5スロットの設定を追加
3. 新しい `type` が必要なら `src/avatar/ProceduralAvatar.jsx` に形状を追加
4. `npm test` で検証。チャットのキーワードは `styleRules.js` から自動で読み込まれます。

## チャットへの反映（`src/fashion/knowledge.js`）

トレンドの要点を短く言い換えて、チャットの返答用に持たせています（外部AI・記事本文の転載なし）。

| 入力例 | 動作 |
| --- | --- |
| 「デートっぽく」「ゆめかわ」「ライブ行く」「秋っぽく」「運動する」「盛りたい」 | 気分・シーンから衣装を自動で選び、トレンド流の理由を添えて着替える（`SCENES`） |
| 「トレンドは？」「抜け感のコツは？」「バッグ／差し色／靴／帽子／レイヤードのコツ」 | 着替えずにアドバイスだけ返す（`TOPICS`） |
| 「今のコーデのポイントは？」 | 現在の衣装の mood・シルエット・配色を `styleRules.js` から説明 |
| 「おすすめは？」 | 今と違う4系統からひとつ選んで着替える |

知識を増やすときは `TOPICS`（アドバイス）か `SCENES`（気分→衣装）にエントリを足し、`tests/parser.test.js` に例を追加します。
